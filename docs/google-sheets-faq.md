# FAQ Com Google Sheets

Use uma planilha publica como base de perguntas e respostas.

## Colunas

```csv
pergunta,resposta,palavras
Como funciona?,Atendemos pelo WhatsApp e agendamos pelo painel.,atendimento;agenda
Qual o horario?,Os horarios disponiveis aparecem automaticamente no WhatsApp.,horario;agenda
```

## Publicar Como CSV

1. Abra a planilha no Google Sheets.
2. Use `Arquivo > Compartilhar > Publicar na Web`.
3. Selecione a aba correta.
4. Escolha CSV.
5. Copie o link.
6. Cole no painel em `Configuracoes > Google Sheets FAQ`.

O backend tambem aceita links comuns de planilha e tenta converter para `export?format=csv`.
